# Linux VPS 隔离验证记录

## 结论与范围

2026-09-11 已在真实 Ubuntu VPS 上完成非特权隔离验证，全部已执行测试退出码为 0。
这不是完整安装/卸载验收，也不代表全系统事务化已经完成。

用户要求不得中断现有业务，因此没有安装系统软件、注册或重启 systemd 服务、修改防火墙、调整业务容器或使用 80/443 端口。
测试使用独立临时目录、UID/GID 65534、清空附加组、`no-new-privs`、CPU/I/O 低优先级及执行超时。
核心测试同时设置 `GOMAXPROCS=1`、`GOMEMLIMIT=64MiB`；后者是 Go 运行时软内存目标，不是整个进程 RSS 的硬上限。

真实核心日志中的 `invalid-protocol` 拒绝是故意注入的失败场景；对应测试确认原文件未被替换，测试本身成功。

## 业务与清理复核

- 测试前后，三个既有业务容器的 PID、启动时间及重启计数相同，原有健康状态保持。
- IPv4/IPv6 防火墙规则规范化摘要前后一致。比较时剔除 `iptables-save` 的时间注释和流量计数，避免把时间变化误判为规则修改。
- 既有 TCP 22/80/443 仍在监听；没有发现残留测试核心进程。
- 远程临时源码、下载的核心、夹具和日志目录已删除；本地临时上传压缩包也已删除。仓库中的测试源文件和本报告保留，可重新生成测试材料。
- 上述检查未观察到业务容器重启或配置变更，但不等同于对业务请求延迟或可用性做了全程监测。

## 本地私有回环工具

按项目所有者要求，回环 Python 工具仅本地保留，不随当前仓库或发布包分发；本报告保留已完成测试的历史结果。以下命令仅适用于持有该本地工具的维护者，并非克隆仓库即可执行的公共测试入口。

使用已有非特权 Linux 账号，在可写的测试副本中运行；需要 Bash、jq、Python 3 标准库以及已校验来源的 sing-box 核心：

```bash
python3 tests/e2e/loopback-proxy.py --core /absolute/path/to/sing-box
```

测试拒绝以 root 运行，不安装依赖、不调用系统服务管理或防火墙命令。该命令不替代完整 VPS 回归清单。
